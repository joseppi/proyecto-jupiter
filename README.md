# Proyecto Júpiter

Asistente de marketing para videojuegos desarrollado como Proyecto Júpiter de PontIA. Possessed Kingdom será el caso de uso inicial.

## Organización

- [Tablero de Miro: definición del producto](https://miro.com/app/board/uXjVEMnlj6o=/): espacio único para explorar el problema, documentar el MVP, preparar diagramas y reunir referencias.
- [Issues](https://github.com/joseppi/proyecto-jupiter/issues): tareas de implementación y seguimiento.
- GitHub conservará el código, la documentación vigente y las decisiones acordadas conforme avance el proyecto.

## Estado

Fase de definición. La propuesta de MVP cubre descubrimiento de creadores, selección con evidencias, preparación y envío de correos y gestión de respuestas, con revisión humana antes de enviar. El alcance definitivo y las tecnologías se acordarán con el equipo.

Por ahora, este repositorio contiene únicamente este README.
